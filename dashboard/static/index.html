🚀 Setup Guide

Deploy to Railway for free 24/7 hosting.

1

Get a free Groq API key

Sign up at console.groq.com (free, no credit card). Go to API Keys → Create API Key → copy it.

https://console.groq.com
2

Create a Discord Bot & get your token

Discord Developer Portal → New Application → Bot → Enable Message Content Intent → Reset Token → copy it.

https://discord.com/developers/applications
3

Push code to GitHub

Create a free GitHub account, create a new repo, and push the discord-bot-groq folder to it.

git init git add . git commit -m "initial" git remote add origin https://github.com/YOU/REPO.git git push -u origin main
4

Deploy to Railway

Go to railway.app → New Project → Deploy from GitHub → select your repo. Railway auto-detects Python.

https://railway.app
5

Add environment variables in Railway

In your Railway project → Variables tab → add these two:

DISCORD_TOKEN = your-discord-bot-token GROQ_API_KEY = your-groq-api-key
6

Set the start command in Railway

In Railway → Settings → Deploy → Start Command:

python bot/bot.py
7

Done! Invite your bot

Use the OAuth2 URL Generator in the Discord Developer Portal. Scope: bot. Permissions: Send Messages, Read Message History, Read Messages.

📖 Discord Commands
@BotName your question — Chat with the AI
!clearhistory — Clear memory for this channel
!botinfo — Show current bot config
